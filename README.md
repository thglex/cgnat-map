# CGNAT Map Generator (Fixed-NAT)

Gerador web de mapeamento determinístico de portas CGNAT (Fixed-NAT) em conformidade com a **RFC 6598**, voltado para operação de redes ISP e engenharia de borda.

## Recursos
- Cálculo automático de blocos de IPs privados versus pools públicos.
- Definição de razão de clientes por IP público e portas reservadas.
- Filtros dinâmicos e ordenação por colunas na tabela de mapeamento.
- Exportação completa para CSV.
- Suporte a MikroTik RouterOS (v6/v7) e A10 Networks.
